---

## 📌 Проблема (Business Case)

В лечебных учреждениях врачи ежедневно формируют сотни выписных эпикризов и сохраняют их в общую директорию. Ручная обработка этих данных создает ряд проблем:
* Высокие временные затраты: персонал тратит 1.5–3 часа в день на ручной разбор и отправку писем.
* Человеческий фактор: риск отправить медицинскую тайну в не ту поликлинику.
* Задержки передачи данных: замедление процесса диспансерного наблюдения за выписанными пациентами.

## 🚀 Решение

MedDispatch — легковесный Python-сервис, который полностью автоматизирует этот маршрут:
1. Парсинг и распознавание: сканирует исходную папку, извлекает метаданные и определяет принадлежность эпикриза к целевой поликлинике.
2. Сегментация и архивация: формирует изолированные ZIP-архивы персонально для каждого медучреждения.
3. Безопасная доставка: автоматически отправляет архивы по защищенному SMTP-протоколу на верифицированные почтовые адреса клиник.
4. Аудит и логирование: ведет подробный журнал операций для контроля доставки и выявления нераспознанных документов.

---

## 🛠 Технологический стек

* Язык: Python 3.10+
* Обработка данных и парсинг: pathlib, re, python-docx / pdfplumber
* Архивация: zipfile (стандартная библиотека)
* Транспорт писем: smtplib, email.mime
* Конфигурация: json / python-dotenv
