> Настольное приложение с графическим интерфейсом для автоматической классификации, изолированной архивации и защищенной email-доставки выписных медицинских эпикризов по поликлиникам и ведомственным системам документооборота (СМДО).

---

## 📌 Описание проблемы и бизнес-контекст

В крупных стационарах скорой медицинской помощи врачи ежедневно формируют сотни выписных эпикризов (`.rtf`, `.pdf`, `.docx`) и сохраняют их в общую директорию. Ручная обработка этих документов влечет:
* **Рутинные трудозатраты:** медицинский персонал тратит до 2–3 часов ежедневно на ручную сортировку и отправку.
* **Риск утечки данных:** вероятность ошибочной отправки выписки не в ту поликлинику.
* **Гетерогенность каналов:** часть поликлиник принимает документы по электронной почте, а часть — через государственную систему СМДО.

**MedDispatch** автоматизирует весь цикл обработки документов за несколько секунд в один клик.

## ✨ Ключевые возможности

* 🧠 **Интеллектуальный префиксный парсинг:** Распознавание медучреждений по стандарту префиксов в начале имени файла (`10ГП`, `17ДГП`, `ЦРБ`) с алгоритмом защиты от опечаток врачей.
* 🔀 **Двухпоточная маршрутизация (Email vs СМДО):**
  * **Канал Email:** Автоматическая сборка изолированных `.zip` архивов и веерная рассылка через защищенный корпоративный SMTP-сервер (G-Cloud beCloud).
  * **Канал СМДО:** Упаковка документов в специализированную директорию для централизованной загрузки в систему документооборота.
  * **Канал верификации:** Нераспознанные документы копируются в исходном виде (без архивации) в папку `Требуют_Проверки` для мгновенного ручного контроля.
* 🖥 **Современный GUI (CustomTkinter):** Поддержка темной и светлой темы Windows, скругленный интерфейс, отзывчивая многопоточная обработка без зависания окна.
* ⚙️ **Встроенный менеджер настроек:** Добавление, редактирование и удаление поликлиник, настройка SMTP-сервера и редактор шаблона письма с поддержкой переменных `{date}` и `{clinic_name}` прямо в интерфейсе.
* 🧪 **Безопасный тестовый режим (Dry Run):** Проверка правил сортировки и формирования писем без фактической отправки.
* 📦 **Полная автономность:** Сборка в один независимый `.exe` файл (не требует установки Python на рабочих ПК).

## 🛠 Технологический стек

* **Язык:** Python 3.10+
* **Графический интерфейс:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) (Fluent UI / Modern Dark Mode)
* **Транспорт почты:** `smtplib`, `email.mime` (RFC 5322 compliance, UTF-8 Base64 attachment encoding)
* **Архивация и файловая система:** `zipfile` (ZIP_DEFLATED), `pathlib`, `shutil`
* **Многопоточность:** `threading`
* **Сборка бинарных релизов:** `PyInstaller`

## 🚀 Установка и быстрый старт

### Вариант 1. Запуск готового `.exe` (для пользователей)
1. Скачайте архив из раздела [Releases](../../releases).
2. Распакуйте папку и запустите MedDispatch.exe.

### Вариант 2. Запуск из исходного кода (для разработчиков)
```bash
# 1. Клонирование репозитория
git clone https://github.com/Alexey050709/med-dispatch.git
cd med-dispatch

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Подготовка конфигурации
cp config.example.json config.json

# 4. Запуск приложения
python main.py
```

### 🔨 Сборка автономного исполняемого файла (`.exe`):
```bash
pyinstaller --onefile --windowed --collect-all customtkinter --clean --name "MedDispatch" main.py
```

## 🔒 Безопасность и защита данных (152-ФЗ)

* **Изоляция медицинских данных:** Проект сконфигурирован так, что никакие реальные файлы эпикризов, персональные данные пациентов и учетные данные почтовых серверов не попадают в систему контроля версий.
* **Шифрование канала связи:** Отправка почтовых отправлений осуществляется по защищенному протоколу SSL/TLS (порт 465).
* **Разграничение доступа:** Каждое медицинское учреждение получает архив строго со своими пациентами.
